# Ejercicios resueltos - Tema 1A (JS, DOM, TypeScript)

| Archivo | Contenido |
|---|---|
| 01-js-basico.html / .js | 25 ejercicios: prompt, alert, confirm, document.write, variables, operadores, if, switch, for, while, funciones, objetos, forEach |
| 02-js-clases-predefinidas.html / .js | 20 ejercicios: String, Math/NaN, parseInt/Float, Array, Date |
| 03-dom.html | 13 bloques DOM: acceso a nodos, crear/eliminar, eventos, menú desplegable, estilos, classList, forEach, formularios |
| 04-typescript.ts (+ .js compilado, .html) | 16 bloques: tipos, funciones, clases, herencia, interfaces, genéricos |

Uso JS: abre el .html en el navegador, pulsa un botón y mira la consola (F12).
(Los ejercicios con document.write reescriben la página: F5 para volver.)
Uso TS: `tsc -w` en la carpeta y abre 04-typescript.html (consola F12).
